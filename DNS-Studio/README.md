# DNS Studio for Windows 11

مدیریت پروفایل‌های DNS برای Wi-Fi و Ethernet با رابط گرافیکی فارسی و اعمال با دوبارکلیک.

## دریافت و اجرا

۱. فایل‌های پوشهٔ `DNS-Studio` را کنار هم ذخیره کنید. ۲. روی `Start DNS Studio.cmd` دوبار کلیک کنید. ۳. پیام UAC را تأیید کنید. ۴. در لیست بالا شبکهٔ متصل را انتخاب کنید.

**به‌روزرسانی نسخهٔ 1.1:** حل مشکل خالی ماندن لیست شبکه با استفاده از `Get-NetAdapter` (بدون فیلتر سخت‌گیرانهٔ `-Physical`)، تشخیص SSID از WLAN API و مسیر جایگزین `Get-NetConnectionProfile`. اگر لیست باز هم خالی بود، دکمهٔ **کپی گزارش تشخیص** را بزنید.

## قابلیت‌ها

- ثبت پروفایل DNS با نام دلخواه و IPv4/IPv6
- ذخیرهٔ DNS فعلی پیش از اولین تغییر، بازیابی پشتیبان و سوییچ با دوبارکلیک
- تشخیص شبکهٔ Wi-Fi یا کابلی و پایشگر اختیاری تغییر شبکه (Scheduled Task)
- عدم نیاز به وابستگی خارجی؛ Windows PowerShell 5.1

## ملاحظات

- تغییر DNS نیازمند Administrator است. اطلاعات در `C:\Program Files\DNS Studio` ذخیره می‌شود.
- در برخی درایورها، استفاده از fallback می‌تواند نام اتصال Windows را به‌جای SSID واقعی نمایش دهد. وقتی هویت شبکه مشخص نباشد، تغییر DNS غیرفعال می‌شود.
- DNS-over-HTTPS، سیاست‌های DNS سازمانی و VPN در این نسخه مدیریت نمی‌شوند.
- روی رایانهٔ ویندوز ۱۱ شما هنوز آزمایش عملی نشده است؛ قبل از استفاده روی شبکه‌های حساس، از تنظیمات نسخهٔ اولیه پشتیبان بگیرید.
