DNS Studio v1.1 | مدیریت DNS برای Wi-Fi و Ethernet در Windows 11
==========================================================

محتویات این بسته:
  • Start DNS Studio.cmd  ← برای اجرای اولیه روی آن دوبار کلیک کنید.
  • DNS-Studio.ps1         ← کد کامل برنامه، قابل مشاهده و ویرایش.
  • README-FA.txt         ← همین راهنما.

نصب و اجرای اول
--------------
۱) فایل ZIP را در یک پوشه استخراج کنید (داخل ZIP اجرا نکنید).
۲) روی Start DNS Studio.cmd دوبار کلیک کنید.
۳) اگر پیام UAC ویندوز ظاهر شد، Yes را بزنید. دسترسی مدیر لازم است.
۴) برنامه به طور خودکار در C:\Program Files\DNS Studio نصب می‌شود؛ میان‌بر
   DNS Studio نیز روی Desktop ایجاد می‌شود. از این پس همان میان‌بر را اجرا کنید.
۵) فایل دادهٔ «dns-profiles.json» در کنار نسخهٔ نصب‌شدهٔ اسکریپت ساخته می‌شود.
   پیش از هر تغییر در فایل داده، نسخهٔ قبلی در «dns-profiles.backup.json» نگه داشته می‌شود.

شروع سریع؛ با مثال Wi-Fi به نام MIDLINK
-------------------------------------
۱) به MIDLINK وصل شوید و در فهرست بالای برنامه «Wi-Fi: MIDLINK» را انتخاب کنید.
۲) روی «ذخیره DNS فعلی» بزنید، مثلاً نام «DNS اولیه MIDLINK» را انتخاب کنید.
   حالت دستی یا خودکار (DHCP) نیز همراه آدرس‌ها حفظ می‌شود.
۳) روی «پروفایل جدید» بزنید، نام دلخواه تعیین کنید، مثلاً «Cloudflare».
   در IPv4 گزینه «دستی» و آدرس‌های 1.1.1.1, 1.0.0.1 را وارد کنید.
   IPv6 می‌تواند «بدون تغییر» باشد.
۴) پروفایل جدید را ذخیره و در فهرست، روی آن دوبار کلیک کنید.
۵) برای آنکه در جابه‌جایی میان Wi-Fiها DNS شبکهٔ قبلی روی شبکهٔ جدید باقی نماند،
   گزینه «سوییچ خودکار» را فعال کنید (در اولین اعمال هم دربارهٔ آن پرسیده می‌شود).
۶) برای بازگشت به وضعیت قبل از نخستین تغییر، «بازگردانی اولیه» را بزنید.

چه کاری انجام می‌دهد؟
-------------------
• هر DNS ذخیره‌شده «نام» دارد و قابل ویرایش/حذف/اعمال دوباره است.
• وضعیت فعلی DNS خوانده می‌شود و پیش از نخستین تغییر هر شبکه نسخهٔ پشتیبان
  اولیهٔ آن ضبط می‌شود، حتی اگر قبلاً «ذخیره DNS فعلی» را نزده باشید.
• Wi-Fi از طریق Windows WLAN API (SSID و نام پروفایل واقعی) شناسایی می‌شود.
  از این رو به انگلیسی/فارسی بودن ویندوز وابسته نیست.
• Ethernet با ترکیب کارت فیزیکی + نام شبکهٔ Windows + آدرس Gateway شناسایی می‌شود.
• فقط کارت فیزیکی انتخاب‌شده تغییر می‌کند؛ VPN/کارت‌های مجازی هدف نیستند.
• IPv4 و IPv6 جداگانه «دستی»، «خودکار» یا «بدون تغییر» دارند.
• برای Wi-Fi ابتدا API مربوط به DNS پروفایل ویندوز امتحان می‌شود.
  اگر این روش در نسخه/وضعیت سیستم نتیجهٔ لازم را ندهد، برنامه از فرمان‌های
  پشتیبانی‌شدهٔ ویندوز برای رابط فعال استفاده می‌کند.
• با فعال‌بودن پایشگر، هر ۱۰ ثانیه شبکهٔ جاری بررسی می‌شود و تنظیم ذخیره‌شدهٔ
  مخصوص آن شبکه دوباره اعمال می‌شود، اگر ویندوز یا برنامه‌ای آن را عوض کرده باشد.
• پایشگر هنگام ورود به ویندوز با Scheduled Tasks و با همان حساب کاربریِ مدیر
  و دسترسی بالا اجرا می‌شود. کد آن در Program Files محافظت شده است.

مهم؛ محدودیت‌ها و احتیاط‌ها
-------------------------
• روش‌های معمول تغییر DNS در ویندوز در سطح رابط شبکه هستند، نه صرفاً SSID.
  برای رفتار مطمئن مبتنی بر SSID، پایشگر خودکار را روشن نگه دارید.
• در صورت رفتن از یک شبکهٔ مدیریت‌شده به شبکه‌ای که برایش پروفایلی تعریف نشده،
  پایشگر DNS آن کارت را خودکار (DHCP) می‌کند تا DNS شبکهٔ قبلی باقی نماند.
  اگر شبکهٔ مقصد نیاز به DNS اختصاصی دارد، پیشاپیش پروفایلش را ثبت/اعمال کنید.
• برای Ethernet ممکن است دو شبکهٔ متفاوت با نام و Gateway یکسان از هم
  قابل تشخیص نباشند. برای این محیط‌ها نام/شبکه را با دقت بررسی کنید.
• DNS-over-HTTPS / DNS-over-TLS / قالب رمزگذاری و سیاست‌های NRPT در این نسخه
  خوانده و ذخیره/بازگردانی نمی‌شوند. ابزار فقط آدرس سرورهای DNS را مدیریت می‌کند.
  برای DNSهای رمزگذاری‌شده یا شبکهٔ سازمانی با سیاست اختصاصی از ابزار استفاده نکنید.
• در مرورگرهایی که «Secure DNS» مستقل دارند، DNS مرورگر ممکن است از ویندوز
  پیروی نکند.
• تغییر DNS ممکن است موقتاً ارتباط اینترنت را قطع کند. برنامه برای خطای اعمال
  سعی می‌کند وضعیت قبل از عملیات را برگرداند؛ پشتیبان اولیه در فایل باقی می‌ماند.
• در اولین اجرا و اجرای رابط کاربری، تأیید UAC لازم است. روی سیستم‌های
  محدودشده توسط سازمان امکان ثبت پایشگر وجود ندارد.
• برای امنیت، برنامه از پوشهٔ ZIP/Downloads به صورت دائمی با دسترسی مدیر
  اجرا نمی‌شود؛ در Program Files نصب و سپس اجرا می‌شود.
• فایل data حاوی نام شبکه‌ها و DNSهاست؛ هیچ رمز Wi-Fi ذخیره نمی‌شود.

خاموش‌کردن و برداشتن نصب
-----------------------
۱) برنامه را باز کنید و تیک «سوییچ خودکار» را بردارید.
۲) میان‌بر Desktop را حذف کنید.
۳) در صورت نیاز از C:\Program Files\DNS Studio\dns-profiles.json یک کپی بگیرید.
۴) پوشهٔ C:\Program Files\DNS Studio را با دسترسی مدیر حذف کنید.
   اگر پیش از حذف پوشه پایشگر خاموش نشود، وظیفهٔ زمان‌بندی‌شده باقی می‌ماند.

بازیابی دستی DNS خودکار در مواقع اضطراری
---------------------------------------
PowerShell یا Command Prompt را به صورت Administrator اجرا کنید؛ با فرض اینکه
نام کارت Wi-Fi شما «Wi-Fi» است، این دو دستور را وارد کنید:
  netsh interface ipv4 set dnsservers name="Wi-Fi" source=dhcp
  netsh interface ipv6 set dnsservers name="Wi-Fi" source=dhcp

اگر نام رابط شما چیز دیگری است، آن را از Settings یا فرمان
Get-NetAdapter در PowerShell پیدا کنید.

مشخصات فنی
----------
نیازها: Windows 11، Windows PowerShell 5.1، .NET Framework داخلی ویندوز.
بدون پکیج خارجی، بدون اینترنت برای اجرای ابزار، بدون جمع‌آوری داده/تله‌متری.
کد اصلی باز است و می‌توانید قبل از اجرا آن را با ویرایشگر متن بررسی کنید.

توجه: این نسخه در محیط ویندوز واقعی در این جلسه اجرا و تست نشده است.
پیشنهاد می‌شود بار اول روی شبکه‌ای که دسترسی بازیابی آن را دارید آزمایش کنید.

اصلاحات نسخهٔ 1.1: حل مشکل خالی بودن فهرست شبکه‌ها
------------------------------------------------
• قبلاً فقط خروجی Get-NetAdapter -Physical بررسی می‌شد. برخی درایورها
  کارت Wi-Fi متصل را در این فیلتر نمایش نمی‌دهند. اکنون همهٔ کارت‌های
  فعال بررسی می‌شوند و کارت‌های مجازی شناخته‌شده حذف می‌شوند.
• اگر Windows WLAN API نام Wi-Fi را برنگرداند، برنامه از نام اتصال
  Get-NetConnectionProfile استفاده می‌کند؛ کنار آن «جایگزین» نمایش داده می‌شود.
• در صورت خرابی ابزار Get-NetAdapter، مسیر جایگزین CIM نیز وجود دارد.
• دکمهٔ «کپی گزارش تشخیص» اضافه شده تا در صورت خالی بودن فهرست،
  وضعیت آداپتورها و اطلاعات عیب‌یابی در Clipboard قرار گیرد.
  گزارش حاوی نام شبکه و شناسهٔ کارت است؛ قبل از ارسال عمومی بررسی کنید.
• اگر هویت شبکه قابل تشخیص نباشد، ممکن است کارت در فهرست دیده شود ولی
  اعمال DNS روی آن برای جلوگیری از تغییر اشتباه غیرفعال است.

ارتقای نسخهٔ قدیمی بدون حذف تنظیمات
----------------------------------
۱) فایل‌های این نسخه را استخراج کنید.
۲) Start DNS Studio.cmd را دوبار کلیک کنید و UAC را تأیید کنید.
۳) برنامه نسخهٔ نصب‌شده در Program Files را جایگزین می‌کند و فایل
   dns-profiles.json قبلی را نگه می‌دارد.
۴) اگر باز هم فهرست خالی بود، روی «کپی گزارش تشخیص» کلیک کنید و
   محتوا را برای رفع اشکال بفرستید.

نکته: این اصلاح از نظر کد بررسی شده ولی روی دستگاه ویندوزی شما
اجرا و تأیید نشده است. در سیستم‌های مجهز به VPN یا درایور سفارشی،
ممکن است برای تشخیص کامل به گزارش نیاز باشد.
